## Bugs found and repaired

- Transient CDN transport failures could abort an otherwise valid original download. Idempotent storage GETs now retry within the configured limit, with bounded backoff. Validation errors and uncertain writes do not automatically retry.
- ReadCube changes `user_data.modified` after metadata PATCH. Readback now ignores only that audit field while preserving strict checks on user content, attachments and List memberships. The corrected two-record live update/restoration passed.
- Metadata preflight held the query-cache lock across the whole batch. It now uses a separate batch lock; individual writes retain cache invalidation. A deterministic concurrent regression test verifies that a blocked preflight does not block a warm library query. This lock-only change was verified locally after the live run without repeating remote writes.

The completed live run used version 0.3.0 with the download/readback fixes; version 0.3.1 adds the final lock fix. Final validation: **224 tests passed, 2 opt-in tests skipped; real offline stdio initialization reports v0.3.1 and 41 tools.** The separately orchestrated 25 live checks are additional to the opt-in pytest tests.
